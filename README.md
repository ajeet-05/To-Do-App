# 📋 To-Do App with Event Listeners

A clean and responsive **To-Do Application** built using **HTML, CSS, and Vanilla JavaScript**, focusing on **DOM Manipulation** and **JavaScript Event Listeners**. Users can add, manage, and delete tasks through a beautiful modal popup interface.

## ✨ Features

- ➕ Add new tasks using a custom modal popup
- 📝 Task title and optional description
- 📊 Dynamic task counter
- ❌ Delete tasks instantly
- 🎉 Success toast notifications
- 📱 Responsive mobile-inspired UI
- ⚡ Built entirely with JavaScript Event Listeners
- 🎨 Modern glassmorphism-inspired design
